Nothing in the system is ever really deleted. Here is how to put the common mistakes right.

## Removed something by accident

Removing a customer, contact, address, unit, photo, scan, part, bin, labor line or maintenance plan shows a message with **Undo**. Press it straight away. A removed customer, unit or part can't be opened from the app afterwards, so ask an admin if you missed the Undo.

::: roles admin
A removed user can be brought back from **Users**: turn on **Show removed**, then **Restore user**.
:::

## Changed something you shouldn't have

Change it back and save. Every change is kept in the history, so an admin can see the old value in the [audit log](help:audit-log). A unit's page also shows its own **Change history**.

## Wrong stock count or delivery

Parts staff can reverse the line in the part's **Stock history**. See [Receive and count stock](help:parts-stock).

## Parts put on the wrong work order

Return them to stock from that work order, then add them to the right one. See [Parts on a work order](help:parts-on-work-orders).

## Wrong owner or sale

- Fix the price, reason or invoice number with the pencil in **Ownership history**.
- An admin can undo the latest change of owner. See [Change owner](help:change-owner).
- An admin can void a sale recorded from a quote. See [Record a sale](help:record-a-sale).

## Wrong import

Undo the whole import. See [Undo, retry or discard an import](help:undoing-an-import).

## Work order completed or cancelled too soon

Press **Reopen** on the work order.
